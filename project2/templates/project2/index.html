Methodology note: PDP and ALE implementation

Both PDP and ALE above are implemented manually (see feature_effects.py), without using any explainability library, as required by the assignment.

PDP is computed by building a grid of values across the selected feature's range, replacing that feature's value with each grid point for every observation in the dataset, obtaining the model's predicted class probabilities, and averaging them across all observations at each grid point.

ALE is computed by dividing the feature into bins and calculating the local effect within each bin before accumulating those effects across bins (and centering the final curve to mean zero). Calculating a local effect requires a partial derivative of the predicted probability with respect to the feature:

  • For logistic regression, the partial derivatives are computed exactly, using the analytical derivative of the softmax probabilities with respect to the feature (a closed-form Jacobian derived from the fitted coefficients — no approximation involved).
  • For the decision tree, the prediction function is piecewise constant and not smoothly differentiable (it has no real derivative — it is flat within each leaf and jumps only at split thresholds), so a discretization is used instead: a finite-difference approximation of the local effect, with the step size tied to each bin's width so the approximation actually captures the tree's behavior across a meaningful interval rather than measuring an infinitesimal step that would almost never cross a split.
